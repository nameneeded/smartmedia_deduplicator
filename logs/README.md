# Log Directory

This folder stores runtime logs generated by the application.

## Rotation Policy
- Max size: 1MB
- Backups: 5
- Format: Standard `[timestamp] LEVEL | logger | message`
- Default file: `app.log`

## Tips
- Logs are not active until you call `setup_logging()`
- Avoid storing sensitive info in logs
- Use `logger.debug()` only in dev or CLI override
