# 🗂️ Project Documentation Overview

This folder contains the evolving documentation for the project, organized around structure, architecture, logic, and process.

## 📁 Contents

| File | Purpose |
|------|---------|
| `architecture.md` | System-wide architecture concepts, modular design notes, component responsibilities |
| `sequence.md` | Sequence flows, agent communication, and process order |
| `project_structure.md` | Auto-generated file tree using `generate_project_structure_tree.py` |
| `app_requirements.md` | Tracked technical and system requirements for testability and evolution |
| `philosophy.md` | Best practices, coding values, and evolving guidelines for consistent development |

---

## 🛠 Usage

### 🔄 Regenerate Project Structure
To regenerate the current file tree:

```bash
python scripts/generate_project_structure_tree.py
```
